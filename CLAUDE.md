## Build & Architecture (Eleventy) — READ FIRST
The site moved from hand-written HTML to an **Eleventy build** (2026-06-21). Do NOT
edit HTML in the repo root for migrated pages — edit the **source in `src/`**.

- **Source:** `src/` → **Build output:** `_site/` (git-ignored). Local: `npm install`
  then `npm run serve` (preview) or `npm run build`.
- **Shared layout / chrome (edit once, applies site-wide):**
  - `src/_includes/base.njk` — full page shell (`<head>`, scripts) for Eleventy pages
  - `src/_includes/nav.njk` / `footer.njk` — the shared header & footer
  - `src/assets/core.css` — shared design tokens, nav, footer, buttons
  - Per-page styles: `src/assets/blog.css`, `article.css`, etc.
- **Blog (Markdown):** each post is `src/blog/<slug>.md` with YAML front matter
  (title, date, tag, deck, image, card*, schemaJson, faqJson…). `src/blog.njk`
  auto-generates the index from the `posts` collection (sorted by `order`).
  Output paths match old URLs: `/blog.html`, `/blog/<slug>.html`.
  - **To publish a post:** add one `.md` file in `src/blog/` and push. Done.
- **Main pages:** `src/*.njk` (home, about, contact, resources, the 6 service
  pages, anxiety/depression/trauma, privacy, sms-terms). Each keeps its own body
  + CSS but pulls the shared nav/footer via `{% include %}`.
- **Passthrough (still raw HTML in repo root, copied as-is):** utility pages that
  don't use the standard chrome — `intake.html`, `join.html`, `open-path.html`,
  `thank-you.html`, `404.html`, the `*-preview.html` files, the Google
  verification file — plus asset dirs `images/`, `functions/`, `api/`, `card/`,
  `newsletters/` and root assets. Config: `.eleventy.js`.
- **One-off migration scripts** (already run, kept for reference):
  `tools/convert-posts.cjs`, `tools/convert-pages.cjs`.
